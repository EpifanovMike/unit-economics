# 📊 Калькулятор Unit-экономики, P&L и Точки безубыточности

Интерактивный веб-дашборд для финансового моделирования бизнеса, оценки эффективности маркетинга, сравнения сценариев и расчета точки безубыточности в режиме реального времени с поддержкой всех налоговых режимов РФ (2026).

---

## ✨ Основные возможности

- **Мгновенный пересчет модели:** Автоматическое обновление всех показателей и графиков при изменении параметров.
- **Сравнение сценариев (План А vs План Б):** Ведение двух независимых планов с копированием базового сценария, таблицей сравнения разницы (`Δ`) и диаграммами.
- **Визуализация структуры выручки:** Интерактивное распределение дохода на себестоимость, маркетинг, OPEX, налоги и чистую прибыль.
- **Полная налоговая модель РФ:** Автоматический расчет для УСН (6% и 15%), УСН + НДС (5% и 7%), ОСНО (НДС 22% + Прибыль 25%), ПСН (Патент), НПД (Самозанятые), АУСН (8% и 20%) и ЕСХН. Поля для ввода ставок автоматически скрываются/показываются в зависимости от выбранного режима.
- **Интерактивные подсказки (`?`):** Встроенные тултипы с формулами и расшифровкой терминов.
- **Экспорт и сохранение:** 
  - Автосохранение в `localStorage`.
  - Выгрузка в **Excel (`.xlsx`)** — генерация файла из 5 листов (Сравнение, Исходные данные, P&L Плана А, P&L Плана Б) через библиотеку SheetJS.
  - Адаптивная печать/экспорт в PDF.
- **Светлая и тёмная тема:** Переключатель в шапке (☀️ / 🌙) с сохранением выбора в `localStorage`. Поддержка системных настроек (`prefers-color-scheme`). Тема синхронизирована между калькулятором и справкой.

---

## 🧮 Ключевые метрики

1. **Юнит-экономика и трафик:** покупатели (`B`), средний чек (`AVP`), валовая прибыль на платящего (`ARPPU`), LTV, прибыль на привлеченного пользователя (`ARPU`).
2. **Отчет о прибылях и убытках (P&L):** выручка (`Revenue`), себестоимость (`COGS`), валовая и маржинальная прибыль, EBITDA, НДС к уплате (`VAT Payable`), налоги и чистая прибыль (`Net Profit`).
3. **Эффективность маркетинга и ROI:** CPA, CAC, соотношение `LTV / CAC`, ROMI, ROI, ДРР и срок окупаемости (`Payback`).
4. **Рентабельность и безубыточность:** валовая рентабельность, рентабельность по EBITDA, ROS, точка безубыточности (`BEP`) и запас прочности (`Safety Margin`).

## 🏛 Налоговые режимы (2026)

В калькуляторе реализован расчет для следующих систем налогообложения:

- **УСН 6% (Доходы)** и **УСН 15% (Доходы − Расходы)** — классические режимы.
- **УСН + НДС 5% / 7%** — для тех, кто превысил лимиты по доходам. НДС считается с оборота (без вычетов), плюс налог УСН 6%.
- **ОСНО** — НДС 22% (с вычетом входного) и налог на прибыль 25%.
- **ПСН (Патент)** — вводится фиксированная стоимость патента в месяц.
- **НПД (Самозанятые)** — 6% с выручки (упрощенно).
- **АУСН (8% / 20%)** — автоматизированная УСН.
- **ЕСХН 6%** — сельскохозяйственный налог (Доходы − Расходы).

## 🗂 Структура проекта

Проект написан на чистом **HTML, CSS и Vanilla JavaScript** без использования сборщиков и тяжелых фреймворков:

* `index.html` — разметка дашборда и интерфейс управления.
* `style.css` — адаптивные стили, темы (светлая/тёмная), визуализация графиков и правила печати (`@media print`).
* `formulas.js` — изолированный модуль с математической моделью и налоговыми расчетами.
* `app.js` — управление состоянием, сравнение планов, подсказки, темы и генератор Excel-книги.
* `help.html` — встроенная справка с инструкциями, словарем метрик, описанием налоговых режимов и FAQ.

### Внешние зависимости

* **SheetJS (`xlsx@0.18.5`)** — подключается с `cdn.jsdelivr.net` для экспорта в `.xlsx`. Если CDN недоступен (нет интернета), кнопка Excel выдаст сообщение об ошибке.

## 🚀 Быстрый запуск и развертывание

### Локальный запуск
1. Склонируйте репозиторий или скачайте архив с файлами.
2. Откройте файл `index.html` двойным кликом в любом современном браузере (Chrome, Safari, Firefox, Edge, Яндекс Браузер).
3. Все расчеты происходят на стороне клиента, поэтому для базовой работы сервер не требуется.

### Публикация на GitHub Pages
1. Загрузите файлы репозитория на GitHub.
2. Перейдите в **Settings → Pages** вашего репозитория.
3. В разделе **Build and deployment → Source** выберите `Deploy from a branch`, укажите ветку `main` и корневую папку `/ (root)`, затем нажмите **Save**.
4. Через 1–2 минуты калькулятор будет доступен по публичной ссылке вида `https://<username>.github.io/<repo>/`.

## 🧮 Основные формулы финансовой модели

| Показатель | Формула расчета |
| :--- | :--- |
| **Покупатели (B)** | `Привлеченные пользователи (UA) × Конверсия (C1) / 100` |
| **Прибыль на платящего (ARPPU)** | `Средний чек (AVP) × (1 − Доля себестоимости (COGS) / 100) × Кол-во покупок (APC)` |
| **LTV** | `ARPPU × Время жизни клиента (Lifetime)` |
| **Выручка (Revenue)** | `Покупатели (B) × Средний чек (AVP) × Кол-во покупок (APC)` |
| **Себестоимость (COGS)** | `Выручка × (Доля себестоимости (COGS) / 100)` |
| **Маржинальная прибыль (CM)** | `Валовая прибыль (GM) − Маркетинг (AC) − Коммерческие расходы (SC)` |
| **Прибыль до постоянных расходов (PBFC)** | `CM − Переменные расходы (Materials × B × APC)` |
| **EBITDA** | `PBFC − Административные расходы (Admin OPEX) − Аренда (Area × Rent Rate)` |
| **НДС к уплате (ОСНО)** | `(Выручка × 22/122) − (COGS + Переменные) × 22/122` |
| **Налог на прибыль (ОСНО)** | `(EBITDA − НДС) × 25%` |
| **Налог УСН 6%** | `Выручка × 6%` |
| **Налог УСН 15%** | `(Выручка − COGS − Маркетинг − Аренда − Зарплаты) × 15%` |
| **Чистая прибыль (Net Profit)** | `EBITDA − Налоги (итого)` |
| **Стоимость покупателя (CAC)** | `(Расходы на маркетинг (AC) + Коммерческие расходы (SC)) / Покупатели (B)` |
| **Точка безубыточности (BEP)** | `Постоянные расходы / Маржинальность одной покупки` |

## 📤 Экспорт в Excel (`.xlsx`)

Кнопка **«Excel (.xlsx)»** формирует файл из 5 листов:

| Лист | Содержимое |
| :--- | :--- |
| **Сравнение Планов** | Ключевые метрики обоих сценариев с расчетом разницы (`Δ`). |
| **Исходные данные** | Все введенные значения (UA, C1, AVP и т.д.) для Плана А и Плана Б. |
| **P&L План А** | Полный отчет о прибылях и убытках для сценария А. |
| **P&L План Б** | Полный отчет о прибылях и убытках для сценария Б. |

> ⚠️ Бесплатная версия SheetJS **не сохраняет** жирный шрифт / заливку / границы в `.xlsx` (это Pro-функции). Форматы чисел, ширина колонок и структура сохраняются полностью.

## 📱 Адаптивность и совместимость

* Интерфейс полностью адаптирован для работы на **десктопах, ноутбуках, планшетах и смартфонах** (от `360px` и выше).
* Встроенная страница справки (`help.html`) построена без горизонтальной прокрутки с удобной навигацией по разделам.
* Поддерживается печать и экспорт в PDF через встроенные стили `@media print`.
* Поддержка `prefers-reduced-motion` — анимации отключаются для пользователей с соответствующей настройкой ОС.
* Тёмная тема соответствует уровню контраста **WCAG AA/AAA** для основного текста и акцентов.
